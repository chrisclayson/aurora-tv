Import a TV

On the TV open Settings → On-TV web configuration and read the six-character import code. The code only works while Settings is open.

Push configuration to TV

This sends this profile to a TV running Aurora. On the TV open Settings → On-TV web configuration and read the six-character import code. The code only works while Settings is open. The TV applies the pushed profile when Settings closes.
